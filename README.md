# 多机联动模式（multi-machine-sync）

同一使用者在多台电脑上共用同一智能体账号的联动模式：多台电脑的配置、习惯与任务保持衔接，使用体验接近单台电脑。

由 **天工创新坊** 开发维护，许可 **CC BY 4.0**。

## 有什么用处？

- 一人多台电脑（家里一台、办公室一台、还有台笔记本）时，让智能体的规矩、习惯、技能与脚本跨机保持一致
- 换电脑、新机器初始化时，不必手工拷贝配置文件

## 为什么要用？

把个人配置视为可跨机同步的资产，通过中枢节点与同步包机制，让各台电脑自动获取最新配置。换机器不再意味着把智能体重新调教一遍。

## 如何用？

1. 落地由 wb-profile-sync（跨机同步配置）技能承载：每次会话开始时自动同步
2. 同步范围：记忆文件、人格与用户档案、自建技能、脚本；同步前先生成 `.bak-时间戳` 备份再行覆盖
3. 新机器首次使用：安装智能体并登录同一账号，通过"初始化同步我的配置"手工触发一次
4. 新建命令、技能或任务后，同步登记至命令中心，随同步包跨机

## 不推荐的做法

- 同步含明文密钥的配置文件（存在安全风险）
- 同步数据库、日志、缓存、会话
- 要求使用者手工拷贝配置文件（与自动化同步的初衷不符）
